# AGENTS.md

Guidelines for AI coding agents working in this repository.

## Commit messages

- **Never add `Co-Authored-By` trailers, "Generated with …" footers, or any
  other co-author / attribution lines to commit messages.** The project owner
  is the sole author of every commit.
- Write plain, descriptive commit messages: a short summary line, optionally
  followed by a body explaining the why.
